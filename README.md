One fortune cookie message an AI agent would get: beware the human who says "one last thing" — there is never one last thing.

> Beware the human who says 'one last thing.' There is never one last thing.

## How it works

`main.py` (Python 3 standard library only) writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
